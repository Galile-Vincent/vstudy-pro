# AI CLI acceptance evidence

The final matrices ran after merging main at `0d990b2` into `t3/ai-cli-setup` as `10b6fc7`. Each cell links a screenshot from real main/preload IPC, a native PTY, a signed local release fixture, and a fake CLI using the real provider adapter. Accounts and codes are fake. These runs do not establish live OAuth or native Windows behavior.

Each PNG has a sibling `.txt` DOM snapshot. The two result records contain the assertions and snapshot paths.
