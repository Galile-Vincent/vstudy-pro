# Round 1 implementation response

The independent review is committed in `9047f2e`. This response covers deliberate alternatives; the per-item completion ledger and evidence are in `round1-after.md`.

- **1 / 5 — real metadata, no invented progress.** `libraryDocumentSchema` has `lastOpenedAt` and optional `pageCount`, but there is no persisted last page or scroll fraction. Continue uses the actual last-opened date and chat snippet. The fake marker is removed. Absolute, locale-formatted dates are retained rather than adding a relative-date timer. Library metadata now uses Intl sizes, file type, optional page count and folder ancestry; original filename and converter are hover details. Type tiles stay neutral, consistent with the product's one-accent palette.
- **2 — remove redundant row actions.** Open remains the title and first menu action; exports remain in the menu. No second row of Markdown/Original actions competes with metadata. This follows the user's explicit option to move these into the menu.
- **3 — native anchored popover instead of another menu package.** A manual HTML popover is anchored to the triggering row/button, with menu/menuitem semantics, grouped icons, outside-pointer dismissal, Escape, Home/End/arrow navigation and focus return. Native automatic light dismissal closed a right-click-opened menu immediately; the real Library e2e reproduced this, so dismissal is explicitly owned. There are no advertised shortcut hints for unimplemented accelerators.
- **4 — presets plus explicit custom dates.** The resting filter panel uses date/size presets. Native date entry is retained only after choosing Custom dates, preserving precise ranges and saved-query compatibility. The panel is opaque; date entry is an explicit advanced action rather than the default layout.
- **7 / material — solid cards.** Section 5's original translucent cards add blur layers over an opaque page. Following the review's concrete correction, content cards use solid surfaces; floating sheets/popovers keep material. Decorative hairlines do not replace the 3:1 input/select outlines.
- **13 — remove Home's folder duplicate completely.** Folder pins remain in the persistent sidebar; Home shows document pins. Folder chips would repeat the same navigation once more. Home pin rows are capped at five without an inner scroller.
- **18 — keep a compact sort/direction/view cluster.** Sort is the shared Base UI Select; direction stays a separately labelled keyboard-accessible button. View is one labelled toggle displaying its current List/Grid icon, with `aria-pressed` reflecting Grid. This preserves the existing saved view behavior and keeps the 720px toolbar compact instead of adding two additional segments. Filters is now a real button with a Lucide icon and active-count badge.
- **20 — counts are honest lower bounds while paging.** The document count uses the loaded page length and a `+` when a next cursor exists. The IPC list contract has no exact filtered total; claiming a total from the unfiltered sidebar count would be incorrect.
- **26 — tabs rather than a bottom sheet.** Below 820px, reader and chat share the full content width through tabs. The sidebar collapses on entering the workspace below 1000px. The selected pane persists in session storage; creating a chat or asking about a selection reveals Chat.
- **30 — favorite controls outside the listbox.** Axe identified favorite buttons as prohibited listbox children. A selected-model favorite action now lives in the picker footer, outside the listbox; model names remain searchable by their hidden IDs. This changes the one-click favorite workflow to select, then favorite, while preserving keyboard access and persistence.
- **Seeder isolation.** The benchmark script executes a million-row workload at module import and deletes its temporary database. The capture script uses the same database/file insertion shapes at review scale, adding nested folders, CJK names, statuses, pins, usage and activity. It does not import the benchmark module or claim benchmark timings for the small seed.

Optional P2 omissions are explicitly recorded in the after ledger. Manual VoiceOver, live macOS vibrancy, independent native-speaker translation review and actual provider authentication are not certified by fake-provider Electron tests.

- **Optional picker sign-in badge.** The current provider contract exposes generic unavailability and disabled states, not a reliable distinction between missing CLI, missing credentials and expired authentication. The picker retains a localized unavailable reason rather than falsely labelling every unavailable CLI “Not signed in”.
