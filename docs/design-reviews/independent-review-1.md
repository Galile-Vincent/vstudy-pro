Reviewer: independent senior product designer (review sub-agent). Inspect-only; no source file was changed. Method: `docs/PRODUCT_DESIGN_V2.md` sections 5, 8, 10 (the eight principles), applied to the builders' screenshots and to my own captures of the real app with realistic data.

Temp dir deleted afterwards. Script: `/private/tmp/claude-501/-Users-vc--t3-projects-vstudy-pro/7b361423-7dee-4e22-8a98-fc55f869a3ee/scratchpad/capture.mjs`. Shots (session scratchpad, ephemeral): `/private/tmp/claude-501/-Users-vc--t3-projects-vstudy-pro/7b361423-7dee-4e22-8a98-fc55f869a3ee/scratchpad/shots/{en,ja}-{1200,720}-{light,dark}-{home,home-scrolled,library-all}.png`, `en-1200-light-library-{filters-open,folder,grid}.png`, `en-1200-dark-library-folder.png`, `en-900-light-library-grid.png`. Referred to below as `mine/<file>`.

**Caveats.** Builder shots are viewport-cropped (about 1200x868), so the bottom of Home (Recent activity) was never shown. Window vibrancy and drag-and-drop visual state cannot be judged from Playwright stills. I eyeballed contrast; I did not run `scripts/check-contrast.mjs`. Animation, VoiceOver and real-device rendering are unverified. The tree has uncommitted chat edits (`chat-fixes.css`, `model-picker.tsx`, ...); I judged the chat shots as given.

**Headline.** The structure is sound and the copy tone is good, but the UI still reads as a wireframe: every control carries the same heavy 1px mid-grey outline, every card has equal weight, and the screens never show what the product does for the user. The Library rows and Home dashboard are the weakest. Most of the fix is token-level (borders, radii, button variants, weights), then three structural rebuilds: the Library row, the context menu, and the Home hero.

## 4. Cross-cutting token changes (do once, fixes most screens)

1. **Borders**: `--hairline` 10% ink (light) / 12% white (dark) for everything except input outlines (`--line`).
2. **Radii**: `.home-card` and library cards 14; controls 10; chips 6; menus 14 outer, items 10; sheets/dialogs 20; picker search 0 inside overflow-hidden 14.
3. **Buttons**: primary / secondary / ghost; heights 36 / 32 / 28; focus ring 2px `--focus`, offset 2px, one ring per control.
4. **Type**: display 28/600 · title 17/600 · body 13/400 · label 12/500 · caption 12/400 (nothing below 12px in CJK; 11px only for non-essential Latin captions); CJK line-height: body 1.7, headings 1.35, buttons 1.2.
5. **Material**: solid cards; translucent + blur reserved for floating surfaces; keep the reduced-transparency fallback.
6. **Native controls**: replace `<select>`, `<summary>` disclosure markers, `<progress>` and date inputs with styled equivalents (Base UI is already a dependency).
7. **Layout**: page padding 32px everywhere; sidebar becomes a drawer below 900px (below 1000px while reading); content max-width 1120px centred on very wide windows.
8. **Reveal-on-hover/focus** utility (`[data-reveal]`: opacity 0 → 1 on `:hover`, `:focus-within`, `[aria-selected=true]`) for row actions, tree "…" and reorder arrows; never `display:none`, so keyboard and VoiceOver users keep access.
9. **Empty-state component**: icon 24px, heading 17/600, one 13px line, one primary action, optional secondary link; one instance used by Home hero, Library, no-results, blank chat, with different copy.

## 5. What is working (kept short)

- Calm, consistent tone of copy; per-locale hand-written text reads naturally (ja "小さな疑問から、理解が広がります。" and zh-Hant "帶著一點好奇，慢慢讀。").
- Token file exists with the specified radius, spacing and type scales; the work is applying them, not inventing them.
- The ink-filled primary button with inverted dark variant gives a clear single accent.
- Selection state in Library list (left bar + light fill) is quiet and legible.
- Onboarding keeps one idea per step, with skip available and focus moved to the heading (per the e2e).
- Locale handling: system font stacks, `lang` attribute, no clipping at 720 in ja/zh-Hant in the shots I opened.
- Empty library already follows the icon / heading / line / action pattern; it needs to lose the duplicated button, not be redesigned.
- Chat transcript and the final composer-redesign states (chips, inline picker) are a clear step up from the earlier iterations.
