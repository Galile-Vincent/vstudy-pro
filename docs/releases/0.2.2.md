# VStudy Pro 0.2.2

A polish and distribution release. Generated build notes record each artifact's actual signing and notarization status.

## Changed

- Course cards and course headers use soft, smooth gradient art with no lines, dots, stripes or grain.
- App headers are borderless at rest and fade in a soft edge only when content scrolls under them.
- Switching theme, light or dark, contrast or glass now animates smoothly instead of cutting.
- Website redesigned on clean neutral surfaces with a borderless header and smooth theme transitions.
- macOS and Windows get direct installer downloads selected by platform, with visible architecture alternatives and checksums.
- Windows uses a per-user installer without administrator elevation, native window controls, Ctrl shortcuts, and DPAPI for saved credentials.
- Codex CLI stays unavailable on Windows because its verified transport requires the macOS kernel sandbox. API-key providers remain available.
- Windows Python conversion has process deadlines and Python network guards but no equivalent kernel network deny. Windows ARM64 conversion uses x64 Python on Windows 11.
