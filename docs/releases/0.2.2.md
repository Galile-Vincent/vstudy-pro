# VStudy Pro 0.2.2

A polish release. This build is unsigned and not notarized.

## Changed

- Course cards and course headers use soft, smooth gradient art with no lines, dots, stripes or grain.
- App headers are borderless at rest and fade in a soft edge only when content scrolls under them.
- Switching theme, light or dark, contrast or glass now animates smoothly instead of cutting.
- Website redesigned on clean neutral surfaces with a borderless header and smooth theme transitions.
