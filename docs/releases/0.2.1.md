# VStudy Pro 0.2.1

A visual release. This build is unsigned and not notarized.

## Changed

- Courses redesigned around art-led course cards, a themed gradient backdrop, a full-width course header, and compact deadline chips and progress rings.
- Reader, chat, Home, Library and the shell redesigned ("Quiet folio"): a soft reading page, a small dismissible reading tip, a structured assistant welcome with contextual suggestions, a docked composer, and a gentle no-AI state.
- New app icon.
- README (English, 繁體中文, 日本語) and the website refreshed with curated screenshots of the real product.

## Fixed

- Release files no longer contain spaces, so `SHA256SUMS.txt` verifies after GitHub renames assets.
