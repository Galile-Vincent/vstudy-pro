# VStudy Pro 0.4.1

Tabs arrive, and installing gets easier. The macOS build is signed with a Developer ID and notarized by Apple. The Windows build is unsigned.

## Added

- **Tabs.** Keep several courses, Moodle homework pages, documents and chats open at once and switch like in a browser. Each tab keeps its own back and forward history, scroll position and draft. Open a new tab with Cmd or Ctrl+T, close with Cmd or Ctrl+W, and jump with Cmd or Ctrl+1 to 9. Drag tabs to reorder them, or use the all tabs list when many are open. Your tabs come back after a restart.
- **Bounded memory.** At most four web pages stay live per window. Background pages are discarded after ten minutes or under memory pressure, then reload when you return. Pages with unsaved typing, an import in progress, or a sign-in popup are never discarded.
- **Easy install.** A one-line Terminal installer for macOS and a PowerShell installer for Windows that verify the download checksum. The README and the website download page now have a plain step-by-step guide.

## Fixed

- Undo after deleting a document now restores it.
- The macOS app no longer shows "Electron" in its helper process names.
- A finished Moodle import no longer repeats when you go back.

## Notes

- Windows installers are unsigned. SmartScreen warns on first launch; the README explains each step.
- The macOS app asks once for access to its saved credentials in Keychain after updating from an unsigned version. Choose Always Allow. Your library and settings are untouched.
- Updates are still manual. Download the new installer or re-run the one-line install command.
- Tab memory limits are starting values and are not yet tuned on real use.
- Intel Mac and Windows ARM64 are still planned.
