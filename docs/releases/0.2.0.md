# Proposed 0.2.0 release notes

This is a release-note proposal. Package versions remain 0.1.0 and no tag is created.

## Added

- Multiple Moodle school accounts, local school search, custom HTTPS roots, verified password and SSO sign-in, course content, deadlines, announcements, grades, and file import.
- Isolated in-app Moodle content views with account session recovery and contained downloads.
- A course study agent with explicit approval for tasks, exams, plans, reminders, and calendar exports.
- Searchable document, course, and general chat history with filters, pins, titles, archives, and deletion.
- Complete light and dark theme packs, contrast and glass controls, and validated custom theme import and export.
- Storage inventories, bounded account caches, confirmed maintenance, portable backup, staged restore, and integrity checks.
- Guided first-run onboarding and a sample document.

## Engineering

- Automatic typed locale registration with the existing pseudo-locale.
- Immutable migration registry separated from store lifetime management, with upgrade coverage through version 21.
- Main and shared module contracts, subsystem diagrams, and current contributor procedures.
- Patched minimatch resolution for build tooling and reconciled vendor source provenance.

## Release acceptance still required

Run signed packaging with the release credentials, notarization, and the supported macOS acceptance workflow. Optional live-provider and converter integrations require their own configured environments. Unit checks and build results do not prove those external integrations.
