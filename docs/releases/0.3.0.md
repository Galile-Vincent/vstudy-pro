# VStudy Pro 0.3.0

Windows arrives, agents can read your courses, and setup is guided. This build is unsigned and not notarized.

## Added

- **Windows (x64).** An installer that needs no administrator rights. The Codex CLI provider stays macOS-only. Intel Mac and Windows ARM64 are planned.
- **Agent access (MCP).** Let Claude Code, Codex, Antigravity and other agents read your Moodle courses, deadlines, files and grades through a local, user-approved bridge. Access is off by default, scoped, expiring and revocable. Writes need your approval each time. Assignments are saved as drafts only; you always submit in Moodle yourself. Quizzes are read-only.
- **Guided AI tool setup.** Install, sign in and test Claude Code, Codex or Antigravity from inside the app, with step-by-step help, an embedded terminal, and updates that never interrupt a running chat.
- **Any Moodle school.** Connect any school whose Moodle has the mobile service on.

## Changed

- New butterfly app icon and branding.
- Calmer course art with smooth gradients, borderless headers and animated theme changes.
- Redesigned Home, Library, Reader and Courses.
- A redesigned website with a Windows and macOS download menu.

## Notes

- Downloads are unsigned. macOS and Windows will warn on first launch; the README explains each step.
- Document conversion on Windows needs Python through uv; first-run conversion on a clean Windows machine is not yet verified.
- Live-school sign-in, Developer ID signing and notarization are not yet verified.
