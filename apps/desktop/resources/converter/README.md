# Local document converter

`convert.py <input> <temporary-output.md> <library-output.md>` converts a local file.
PDFs use pdfplumber 0.11.9 with the pure stages in `pdf_md/`; exceptions and absent
text layers fall back automatically to MarkItDown 0.1.9. Other formats use
MarkItDown. A `<temporary-output.md>.json` sidecar records the successful parser;
main validates it before marking the document ready. No-text errors use the
structured `NO_TEXT_LAYER` code only after fallback also produces no text.
PDF raster images use omission placeholders; Office embedded images are exported
to content-addressed library assets. PyMuPDF is development-only.
Failures emit a JSON object on stderr and exit nonzero. Office archives are
checked for expansion limits; Markdown output is capped at 8 MiB.

The main-process `createConverter` starts only on a required-format conversion or
explicit Privacy Retry, never on launch. After native download consent it creates
`userData/converter-venv` with uv (preferred, Python 3.12), or Python 3.10+ and pip,
using `requirements.lock.txt` with required hashes. A requirements hash marks
successful installation. Offline mode prevents installation downloads. Failed installation can be retried by calling
`ensureReady` or converting again. `onProgress` receives bootstrap milestones.
Conversion uses a temporary working directory, a scrubbed environment, a
120-second timeout, and bounded process output. The worker stops after idle time
(default five minutes, configurable one to sixty) and restarts on demand. On macOS
workers run inside a native deny-network sandbox as well as Python network guards.
This does not establish least-privilege filesystem isolation. Installer networking
is separate and requires consent; PyPI hosts and possible GitHub Python downloads
are disclosed before installation.

Supported library imports: DOCX, PPTX, XLSX, HTML/HTM, PDF, CSV, MD, TXT.
MD/TXT bypass Python. Source files are capped at 50 MiB. Fixtures under
`test-fixtures/converter` are generated by the adjacent standard-library-only
`generate.py`; integration tests bootstrap the real pinned converter.

On Windows, install native `uv.exe` in `%USERPROFILE%\.local\bin`, or Python
3.10+ in its standard per-user Programs/Python location. Command wrappers such
as `.cmd` are not launched. The venv uses `Scripts/python.exe`. Windows receives
SystemRoot and isolated TEMP, USERPROFILE, APPDATA, and pip configuration values.
Python uses the Windows process memory API for the memory watchdog. Windows lacks
the POSIX file descriptor, file-size, and core-dump limits and the native macOS
network-deny sandbox. Python socket guards cannot contain native code. Parent
Node workers still enforce timeout, output, and Markdown size limits. Windows
process trees use taskkill while the leader is alive; Unix process groups also
allow descendants to be reaped after their leader exits.
