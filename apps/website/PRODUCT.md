# VStudy Pro website

## Platform

Web. Astro generates static marketing and documentation routes.

## Users and purpose

Students evaluating a Mac and Windows workspace for Moodle coursework, reading, and study planning. The home page explains the product and leads to the GitHub release or first-launch guide. Documentation describes current behavior and limits.

## Confirmed constraints

Keep English, Traditional Chinese, and Japanese routes. Use real app screenshots with a demo-data caption. AI is optional and requires the student's provider. Schools must enable compatible Moodle mobile services. Current builds are not notarized. No invented customers, testimonials, or availability claims.

## Brand commitments

The owner requested clean neutral light and dark backgrounds, expressive type, a slow aurora behind the product, mixed bento cards, smooth theme changes, and a header without a bottom line. T3 Code and assistant-ui are craft references. The implementation brief authorizes three prototypes and an implementation-agent decision.

## Current feature evidence

Reader screenshots include converted figures, original PDF pages, and page attachments. Appearance exposes nine packs, Card transparency, text controls, and the default document opening method. Connect AI has one next action at a time. Usage examples are synthetic subscription windows, separate from API billing and user-set budgets. The website previews the first six palettes; the capture archive covers all nine in both schemes.
